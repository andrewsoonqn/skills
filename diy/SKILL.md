name: diy
description: Help the user do it themselves. Use when the user wants to learn on top of getting things done.
disable-model-invocation: true
---

I want to do this task myself. Please save the instructions from start to finish into a Markdown file. Then, we would go through the whole process together in a human-in-the-loop manner, where I will come back to you after I finish each step/stage.

Make the instructions “braindead” and explicit so I rarely need to ask basic follow-up questions.

The goal is maximum learning. Structure each section with progressive disclosure so I can attempt it before seeing the answer:

1. The purpose or question we are addressing
2. A high-level implementation approach
3. A code skeleton
4. The complete implementation

Present each level separately, moving from the problem, to an English-language approach, to a code skeleton, and finally to the complete code.

A section could follow the format in the example, EXAMPLE.md
